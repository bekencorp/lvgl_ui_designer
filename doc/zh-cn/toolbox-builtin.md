# 内置工具

内置工具随软件提供，无需安装，打开工具箱即可使用。所有工具都可从工作台工具栏启动；各工具的详细界面、参数与常见问题，请在其窗口内按 **F1** 查看。

---

## 🧰 工具一览

### 工程联动工具

可从工作台启动，读取或写入当前工程数据。其中 **动画效果库** 还支持从画布或组件树的右键菜单打开。

| 工具 | 用途 |
| --- | --- |
| **组件样式库** | 浏览 32 类组件的多种风格与真实渲染效果，可将样式预设一键添加到当前画布 |
| **动画效果库** | 为组件添加进场、退场、强调、循环、交互和数值动画预设，写入时间轴后继续微调 |
| **事件与页面导航地图** | 汇总页面跳转、组件事件与动画触发关系，标出孤立事件、死链、循环跳转和未绑定动作 |
| **资源预算分析器** | 扫描组件树、图片与字体，估算 Flash / RAM 占用，给出 `LV_MEM_SIZE`、图片色深和字体档位建议 |

### 独立工具

不依赖工程，可直接在工具箱中使用。

| 工具 | 用途 |
| --- | --- |
| **LVGL 图片资源转换器** | 把 PNG / JPG / BMP / WebP 转成 LVGL 资源（C 源码或 BIN），支持 LVGL 8.x / 9.x、多种颜色格式与字节序 |
| **图片格式转换器** | PNG / JPG / WebP / BMP 批量互转，支持质量调节、缩放裁剪、透明填充与体积统计 |
| **字体转换工具** | 将 TTF / OTF 转为 LVGL 位图字体，按实际用到的字符裁剪，并比较不同 BPP 的体积 |

---

## 🚀 典型用法

### 转换图片为 LVGL 资源

1. 打开 **LVGL 图片资源转换器**
2. 选择 LVGL 版本、颜色格式、字节序和输出格式
3. 添加图片或整个文件夹，按需缩放、裁剪、旋转
4. 导出 C 源码或 BIN，加入工程资源目录

### 使用组件样式库

1. 打开工程并进入工作台
2. 从工作台工具栏打开 **组件样式库**
3. 选择组件类别与风格，查看真实渲染效果
4. 点击 **「添加到当前画布」**，组件以对应样式插入当前页面

### 为组件添加动画

1. 打开 **动画效果库**，选择并预览动画效果
2. 调整时长、延迟、缓动等参数
3. 选择目标组件，点击 **「添加到工程」**
4. 在时间轴编辑器中继续微调关键帧

> 图片、字体类工具不依赖工程，可直接在工具箱中独立使用。
